### 🧠 Featured Projects

#### 🔹 [Production Multi-Hop RAG with Continuous Evaluation](https://github.com/Ajinkya-Nagarkar/evidence-based-rag-multihop-qa)
`PyTorch` `FAISS` `FastAPI` `RAGAS`

> Hallucination-resistant multi-hop QA over 7,405 HotpotQA examples. Hybrid **BM25 + FAISS** retrieval with cross-encoder reranking lifted Joint F1 from 19.6% to 43.2%. NLI verification drove hallucinated references to zero on a 200-question audit. Served on **FastAPI** at p95 1.2s and $0.004/query, with a RAGAS golden set gating CI.

#### 🔹 [Agentic Honeypot v2](https://github.com/Ajinkya-Nagarkar/REPO-NAME-HERE)
`LangGraph` `MCP` `Postgres` `Langfuse`

> Rebuilt my IEEE-published LLM honeypot as an agent exposing filesystem and network tools via **MCP**. Session checkpointing with retry, timeout, and loop detection cut failed sessions from 18% to 2% (n=150). Red-team eval harness scores deception realism, session length, and escape rate at under $0.02/session.

#### 🔹 [MLOps Pipeline for Solar Plant Degradation Forecasting](https://github.com/Ajinkya-Nagarkar/REPO-NAME-HERE)
`LightGBM` `Airflow` `MLflow` `AWS`

> Forecasts photovoltaic degradation from sensor and weather data, lifting accuracy from 67% to 82.9%. Automated feature and training pipelines on **Airflow** with **MLflow** tracking and gated model promotion. Inference on AWS ECS at p95 under 90ms with drift alerting and a backtesting harness.
